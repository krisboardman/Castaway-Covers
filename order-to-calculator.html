📋 Order to Calculator Helper

In your Shopify admin, go to an order and copy all the custom attribute data (product type, measurements, etc.)

Calculator Links:

Click the link above to open the calculator with measurements pre-filled!

How It Works:

  1. Copy the custom attributes from a Shopify order (the measurements data)
  2. Paste it into the text area above
  3. Click "Generate Calculator Links"
  4. Click the generated link to open the correct calculator with all values filled in!
💡 Tip: You can also manually build URLs like:
file:///path/to/chair_cover_calculator_unified_v2.html?W=28&D=27&H=26&BR=4&F2A=24

Calculator Files:

Make sure these calculator HTML files are in the same folder as this helper:

  • chair_chaise_cover_calculator.html - for chairs, recliners & chaise lounges
  • couch_cover_calculator.html - for sofas/loveseats
  • ottoman_table_cover_calculator.html - for ottomans & tables
  • table_set_cover_calculator.html - for table sets
