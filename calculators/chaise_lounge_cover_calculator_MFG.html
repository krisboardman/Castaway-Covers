Assembly Instructions
  1. Cut a single rectangular panel from the bolt:
    • Length = D + 2×(H − FC) — the chaise depth plus a side drop at each end
    • Width = W + 2×(H − FC) — the chaise width plus a side drop on each side
    • Trim the bolt down to the cover width (no full-bolt-width pieces, no seams)
  2. Draw the wavy pattern around all four outer edges and cut:
    • The wave scoops inward from the straight edge (1.5" deep × 13" per cycle)
    • Round the four corners with a smooth transition so the waves flow continuously around the cover
  3. Install grommets at the four corner positions:
    • 5" in from the back/front edge of the chaise (toward the chaise center)
    • 5" outside the chaise's side edges (in the side overhang)
  4. Install the cover with the chaise lying flat. Run a bungee through each corner grommet, pull it underneath the chaise, and cinch so the excess fabric wraps tight against the underside.
  5. Add fabric glue to any thread ends and Scotch Guard the perimeter.
