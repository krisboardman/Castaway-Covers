Assembly Instructions
  1. Cut each panel (ML × B) from its own bolt
  2. Mark the centerline on each panel
  3. Draw diagonal angle cuts on each side of each panel and cut:
    • On each side drop, mark the diagonal start points
    • Draw a straight line from the back edge to the front edge
    • Verify coverage width at armrest before cutting
  4. Draw wavy pattern around outer edges and cut:
    • Do NOT wave the snap overlap edges (inner joining edges)
    • Wave the outer arm edges and front/back drape edges
  5. Sew in gussets:
    • Sew triangular gusset panels into back flap corners of each panel
    • Use 1" hem seam to attach each gusset
  6. Install snaps along each joining seam:
    • Left panel's right edge overlaps right panel's left edge
    • Male snaps on underside of overlapping panel, female on top of underlying panel
    • For 3-panel: center panel underlaps both outer panels
  7. Add grommets to outer edges only
  8. Prepare bungee loops for outer edges
  9. Add fabric glue to thread ends
  10. Scotch guard ends
