# Identity

## Conclusion

The machine is a **Singer 66**, serial block allotted **July 28, 1927**.
It is not a 15-91, and it is not from 1934.

## Evidence

1. **Serial AB759762** (silver plate, read 2026-10-23). ISMACS lists the block
   AB713676–AB763675 (50,000 numbers) as class **66**, allotted
   **July 28, 1927** [source 1].
2. **Allotment is not the build date.** It is when Singer assigned the numbers to
   a factory; the machine was built on or after it [source 2]. "1927, or shortly
   after" is the honest answer.
3. **The motor does not fit a 15-91.** A 15-91 has a built-on potted motor that
   drives the balance wheel through a Textolite gear, with no belt [source 5]. The
   motor removed from this machine is a separate unit on an L-bracket [observed],
   which matches the belt motors fitted to 66s (BR, Series 4 and BY appear on 66
   variants) [source 3] [source 4].

## How to confirm in 30 seconds

Slide the plate to the left of the needle open:

| You see | It is |
|---|---|
| A round bobbin dropped flat into the bed, in a horizontal hook | **66** [source 4] |
| A long bullet-shaped shuttle | a vibrating-shuttle model (127/128), so recheck the serial |
| A round bobbin case clipped in vertically | a 15-class |

## About the 66

- Introduced the horizontal hook with a drop-in bobbin, still the common design
  on domestic machines [source 4].
- UK (66K) production 1907–1939; US production until 1956 [source 4].
- Variants: 66-1 back-clamping feet; 66-4 side-clamping with BR motor; 66-8
  Series 4 motor; 66-18 BY motor [source 3]. The exact variant of this machine is
  unknown.
- Decals include Red Eye (US), Lotus, Sphinx and a plain decal [source 4].
- No reverse feed; feed dogs cannot drop, so free-motion work needs a cover
  plate [source 4].
