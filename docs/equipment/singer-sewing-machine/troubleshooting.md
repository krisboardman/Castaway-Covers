# Troubleshooting

Find the symptom, then work the checks top to bottom (cheapest first). Use the
camera's `region` crops to read small parts instead of high-detail looks.

## Motor and power

| Symptom | Checks, in order |
|---|---|
| Nothing at all | Outlet; cord continuity; foot or knee controller (carbon controllers fail open); brushes stuck in their tubes [source 5] |
| Runs slow or weak | Belt slipping (too loose or glazed); dry or gummed machine (oil it first, see below); worn or sticky brushes; dirty commutator [source 5] [source 10] |
| Heavy sparking | Worn brushes; dirty or rough commutator [source 10]; brush facing put back rotated |
| Hums, won't turn | Seized shaft (old grease) or machine jammed: turn the handwheel by hand; disconnect the belt to tell which one is stuck |
| Won't stop / runs at full speed | Controller fault (shorted resistance) [source 5] |
| Smell of hot varnish | Stop. Overloaded, or a winding is shorting |

## Machine (stitching)

| Symptom | Checks, in order |
|---|---|
| Handwheel stiff | Oil every oil hole and moving joint with sewing machine oil; leave it overnight on a machine this old; turn by hand until free |
| Skipped stitches | Needle: new, right system (15x1 [source 3]), flat side correct, fully up; needle size matches thread; then hook timing (a technician job) |
| Thread nests underneath | Upper threading wrong, almost always with the presser foot down or thread out of the take-up lever. Re-thread with the foot **up** |
| Loose or loopy stitches | Tension: upper first, then the bobbin tension (the 66 has a tension spring in the bobbin area, not a removable case) [inferred] |
| Breaks thread | Burr on hook or needle plate; old or poor thread; tension too tight; wrong bobbin (must be Class 66 [source 3]) |

## Oiling (machine, not motor)

Use sewing machine oil only, never household or 3-in-1 [inferred: standard
practice]. A drop in each oil hole, the hook race and the moving joints under
the bed; wipe the excess off before sewing on good fabric.
