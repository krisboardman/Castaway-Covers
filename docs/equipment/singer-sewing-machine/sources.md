# Sources

Ranked by trust. "Primary" means Singer's own documents or the collectors'
society that maintains Singer's serial records.

| # | Source | What it gave | Trust |
|---|---|---|---|
| 1 | [ISMACS — Singer AB series serial numbers](https://ismacs.net/singer_sewing_machine_company/serial-numbers/singer-ab-series-serial-numbers.html) | AB713676–AB763675, class 66, 50,000 allotted, July 28 1927; also AB763676–AB773675 class 128 (the misread serial) | primary |
| 2 | [ISMACS — Singer dating by serial number](https://ismacs.net/singer_sewing_machine_company/singer_dating_by_serial_number.html) and [manufacturing dates page](https://ismacs.net/singer_sewing_machine_company/singer_manufacture_dates_by_serial_number.html) | allotment date is not the build date | primary |
| 3 | [ISMACS — Singer class 66](https://ismacs.net/singer_sewing_machine_company/singer-class-66-sewing-machine.html) (via search summary) | low shank, oscillating hook, Class 66 bobbins, 15x1 needles; variant list (66-1 back clamp, 66-4 side clamp + BR motor, 66-8 Series 4, 66-18 BY) | primary-adjacent, high |

## Other manuals worth having

- [ManualsLib Singer 15-91 manual list](https://www.manualslib.com/products/Singer-15-91-353065.html) — 8 manuals incl. parts list, adjusters manual.
- ISMACS manuals section: <https://ismacs.net/manuals.html> — look for a 66 instruction manual.

## Not found yet

- A Singer 66 instruction or adjusters manual with timing specs (try [ManualsLib Singer 66-2](https://www.manualslib.com/products/Singer-66-2-2042987.html) and ISMACS).
- The motor's model and its brush size (needs the data plate).
- A wiring diagram for the motor, light and controller.
